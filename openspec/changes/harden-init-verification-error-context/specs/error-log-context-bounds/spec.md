## Purpose

为 CLI 错误诊断提供可预测的递归脱敏与大小边界，避免异常上下文在落盘前无限扩张，同时保护嵌套结构中的凭据和令牌。

## ADDED Requirements

### Requirement: 错误上下文必须递归脱敏并受预算约束
错误日志 SHALL 对字典、列表和元组上下文递归处理；敏感键及其嵌套变体 MUST 替换为固定掩码。序列化结果 MUST 受总字节预算、节点数量预算和最大嵌套深度预算限制，任何预算耗尽后不得继续保留未处理的上下文内容。

#### Scenario: 嵌套敏感键被遮蔽
- **WHEN** 错误上下文在任意字典或列表层级包含 token、secret、authorization、access key 等敏感键
- **THEN** 对应值在错误日志中统一显示为 `***`
- **AND** 非敏感字段继续保留经过长度限制的值

#### Scenario: 超大容器被截断
- **WHEN** 错误上下文包含超过节点或总字节预算的列表、字典或元组
- **THEN** 日志记录保持合法 JSON
- **AND** 超出预算的部分以稳定的截断标记表示
- **AND** 日志写入规模不随输入容器规模无界增长

#### Scenario: 过深上下文被截断
- **WHEN** 错误上下文嵌套深度超过最大深度预算
- **THEN** 当前分支被替换为截断标记
- **AND** 不递归遍历更深层内容

#### Scenario: 标量上下文保持兼容
- **WHEN** 错误上下文是 null、布尔值、数字或字符串
- **THEN** 仍按既有规则保留或截断
- **AND** 不因预算机制改变 JSON 类型
